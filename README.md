# 💡 Interactive Lamp Login

A beautiful and interactive Lamp Login / Signup page built with HTML, CSS & JavaScript.

Click the lamp to turn it ON / OFF with a smooth glowing effect.

## ✨ Features
- Interactive Lamp ON/OFF animation
- Glowing effect
- Modern Login / Signup Form
- Responsive Design

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## 🚀 How to Use
1. Open `index.html` in your browser
2. Click on the lamp to turn it ON / OFF
3. Enter email & password to Login
